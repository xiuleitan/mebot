# 订阅多图与封面

本轮由 joint 联合开发直接实施，不触发 main 集成。

- 订阅保存有序图片列表，首次选中的第一张默认作为封面。后续添加图片保留原封面；删除封面时使用剩余第一张，删除最后一张后不再显示图片。
- 详情多图直接以横向画廊展示，当前页与下一页之间间隔12dp，下一页露出32dp缩略图，末页露出上一张；图片角落显示当前页／总数。首次从封面所在页展示，保留用户选择的图片顺序，单图仍完整预览。点击哪一张就从该张进入全屏，继续支持左右翻页、左下“删除”、右下“设为封面”与删除确认。首页与订阅页共用该详情。
- 编辑页展示已选缩略图与“添加图片”，系统选择器支持多选。图片与表单草稿保存在本地，稍后继续不丢失；图片添加随表单保存提交，图片查看中的封面设置和删除即时保存。
- 图片本体继续由 LocalMediaStore 可靠复制和去重，聊天图片与订阅图片分别持有关联，删除订阅中的图片不破坏聊天历史或其他 Bot 的附件。

## 数据兼容

安装基线为 schema20，其他开发树为19；共享迁移登记为 `migrations/subscription-images.json`，独占21版本。

新增 `subscription_images(subscriptionId, assetId, position)`，前两列为复合主键，分别引用订阅和媒体；索引包含 assetId 和 (subscriptionId, position)。20→21 仅建新表并从 subscriptions.coverAssetId 回填位置0，原67张表、历史快照、原图文件与1→20迁移保持不变。

表单／操作 JSON 的图片列表为可选字段，旧草稿和旧请求仍可读取、去重；未提供图片列表的生命周期更新保留现有图片。显式图片修改与封面、订阅版本、操作回执、历史快照在同一事务内保存。媒体清理检查补充新表引用。
