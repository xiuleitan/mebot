# 首页闪念仅按实际完成日归档

来源：2026-10-31用户要求：首页仅针对闪念，未完成的持续在今天显示；昨天、前天等历史只显示当天实际完成的记录。没有完成，不留下当日历史闪念卡片，第二天继续展示未完成的可切换卡片。

## 行为

- 今天使用与同排日程等宽等高的普通单张卡片入口，可上下滑动切换所有未完成的闪念（按2026-10-31后续UI要求取代重叠和左右切换）。每日随机种子和当前选择保存在既有Room表中，重开页面保持选择；跨天按新一天的种子组织，固定中的闪念优先保持。
- 历史卡片只来自原闪念的`COMPLETED`状态和`completedAt`，按设备时区的实际完成日期分组。一天完成多条就展示多条，每条只归属一个完成日期。
- 今天完成的，今天可由眼睛查看完成状态；到明天自然归入“昨天”。不将今天完成时间伪改成昨天。
- 曾经展示、切换、停留都不算完成。未完成项不在昨天、前天及更早日期留下卡片；即使几天没有打开App，也只在当前今天的入口展示。
- 从首页或原闪念Bot完成使用相同事实。恢复未完成后，原完成卡片消失，回到今天的可切换入口；再次完成按新的实际完成日期显示。原有眼睛过滤、灰色完成标记、详情和完成后关闭行为继续复用。
- 本轮只变更闪念：首页的日程历史未完成、订阅与经期提醒维持原规则。

## 实现与兼容

在`HomeRepository`移除按旧版`FLASHNOTE`展示事件拼接历史的逻辑。选择闪念只更新既有每日选择，不再为浏览补写展示事件。旧版展示事件原样保留在主库，但不作为首页完成事实读取；不删除用户记录。

完成与恢复仍由原`FlashnoteRepository`事务修改原始状态、完成时间及统计。首页仅读取既有投影，不建立新的业务状态或重复完成记录。

schema21、实体、68张表、历史迁移及媒体格式均不变，无需数据库升级。开发和预览在`codex/joint-theme`实施，不改main、不联系其他会话。

## 验证

使用真实SQLite和可推进的上海时区时钟验证：

1. 旧版连续多日展示的未完成事项、每日切换选择、间隔数日打开和数据库重开：始终只在今天的卡片集合中，旧展示事件仍保留。
2. 在不同日期从首页／原Bot完成多条事项：只按各自实际完成日出现一次，明天查看昨天时仍为完成状态。
3. 本地23:59完成、00:01恢复、再次完成和重开：以实际本地完成日为准；恢复只回到今天，重复完成不刷新完成时间或增加历史卡片。

## 手机检查

1. 首页打开眼睛，向下查看昨天、前天：仅完成的闪念显示灰色和“已完成”，过去未完成闪念不再出现；未完成日程仍在原日期。
2. 在今天的闪念卡片上下切换，打开详情完成两条：眼睛打开时可看见两条完成卡片；未完成事项继续留在今天的普通单卡入口。
3. 把一条已完成闪念恢复：完成卡片消失，该事项回到今天可切换列表。重开App后状态及当前选择保留。
4. 次日打开首页：昨天完成的保留在昨天，剩余未完成闪念继续显示在新的今天，不产生昨日未完成副本。


## 固定首页闪念（2026-11-05）

- 今天的未完成闪念卡片左上角增加小图钉按钮。未固定时仍按每小时自动切换；点击后固定当前闪念，停止自动轮换，重开页面、重启 App 和跨天均保留。文字首行避开图钉与右侧类型标签，后续行使用完整宽度；图钉使用独立48dp触摸区域，不触发卡片详情。
- 固定后仍可上下滑动。实际切换至另一条闪念后解除固定，从这次切换重新计满一小时；未换卡、取消手势或分页回写相同 ID 不解除固定。取消图钉也从当前卡片重新计满一小时。
- 在首页或闪念 Bot 中完成时，同一事务清除固定；随后恢复闪念不会恢复旧固定。删除时通过外键级联清除固定；编辑标题或内容保持固定。只有一条未完成闪念时也可固定，后来新增闪念不挤掉它。
- 结构化状态新增主库单例表 `home_flashnote_pin`，仅保存关联闪念 ID 与更新时间，外键关联原闪念。追加25→26保留数据迁移，冻结已安装的schema1—25、旧迁移与媒体格式。共享版本登记为 `migrations/home-flashnote-pin.json`，不改main或其他分支。

手机检查：

1. 首页点击闪念左上角图钉，应变为固定样式且不打开详情；重开 App 后仍显示同一条和固定状态，超过一小时也不自动换卡。
2. 固定时上下滑动到另一条，固定样式应解除；再次固定再取消，当前卡片应保留，并重新开始每小时轮换。
3. 打开已固定闪念详情点击完成，再恢复，或直接删除：固定状态应清除，今天仍正常展示其他未完成闪念，完成记录仍归到实际完成日。
4. 对比有图、纯文字和各主题，检查图钉不遮标题、卡片尺寸与旁边日程一致；普通点击仍打开详情，左右触摸不误开。

### 固定入口改为闪念标签（2026-11-05）

按用户后续要求移除图钉，改为点击今天卡片右上角的“闪念”标签切换固定。未固定时保留原标签背景；固定时使用当前主题选中色与边框，粉色主题为粉色背景，颜色平滑过渡，文字和标签尺寸不变。标签点击不打开详情，卡片其余位置仍打开详情；纯文字标题恢复首行左侧空间，只避开右侧标签。

既有固定记录、跨天重开保留、手动切换及完成删除后解除、取消固定后重新计满一小时的规则保持不变；继续使用已安装schema26，不修改数据库结构、迁移、历史或媒体格式。已完成历史卡片的“闪念”仍是普通来源标签。
