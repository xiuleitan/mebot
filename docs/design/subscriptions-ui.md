# 订阅主界面

2026-10-28 输入栏统一：使用日程相同的圆形按钮、主题描边、紧凑浮窗操作栏及收起时的键盘／附件面板处理；待发送附件条、移除和继续添加入口共用同一实现。输入加载失败或不满足发送条件时禁用发送，订阅额外在进入后台时提交待保存输入。业务会话与原件保留规则不变，见[各 Bot 底部输入约定](composer-consistency.md)。

详情操作从左到右为「删除／编辑／聊天」，删除使用与日程一致的浅红按钮及确认框；先确认再调用既有删除流程，取消时保留详情。已有聊天、图片、消费数据及已结束列表的保留规则不变，见[各 Bot 详情删除约定](detail-deletion.md)。

本页以2026-10-28用户确认的简化流程为准：仅从聊天创建订阅；详情只保留基本字段、图片、备注和“删除／编辑／聊天”。参考图用于整体卡片样式，当前交互随本页更新。颜色沿用当前主题，三项底部操作使用指定背景色。

## 月度汇总与列表

顶部为两张独立圆角卡片，顶部对齐、间距12 dp、宽度比例1.4:1。左侧本月卡片较大，显示本月年月、32 sp金额和实际持续订阅数量；右侧只显示“上月”和18 sp金额，无确认数据时为“暂无记录”。不显示两处消费标签、即将扣费和历史按钮。

统计口径不变：上月只汇总已确认实际扣费，本月汇总整月已确认扣费与剩余预计计划，同一周期去重。多币种分别显示；预计到期不能自动当成付款成功。旧扣费证据和必要的业务快照保留在主库，不因简化界面清除。

列表卡片上下内边距4 dp、左右8 dp，两行文字不额外加间距，普通字号下卡片约52 dp高，字体放大时自然增高。左侧缩略图宽48 dp，高度跟随文字区域填满，仅保留4 dp上下留白；图片自身不参与行高测量，避免原图尺寸撑高卡片。右侧上行标题使用14 sp粗体、18 sp行高，固定一行，过长时末尾显示省略号。下行左侧显示扣费日期或有效期，右侧金额使用18 sp行高并与周期保持同一行，按文字基线对齐。不显示右箭头，点击整张卡片打开底部详情，查看完整名称。持续与已结束列表使用相同紧凑样式。

取消续费后，卡片下行与详情的“下次扣费”位置均显示“已取消续费”，不再提示未来扣款；原有效期另行保留。在有效期内仍属持续订阅，到期后显示“已到期”并归入“已结束的订阅”。到期由自然日派生，不再写入自动归档操作。旧版已归档记录仍按已结束兼容展示，不提供新的归档功能。

## 简化详情

详情继续使用共用底部弹层的遮罩、返回、220 ms过渡及系统动画设置。详情面板禁止手指拖动和下滑关闭，包括正文滚动到边界后的拖拽；只能通过系统返回、右上角X或点击面板外的遮罩退出。正文仍可在固定面板内独立滚动，展示标题、金额、图片、下次扣费状态、有效期、计费周期、支付方式、账号及备注；备注紧跟在账号下方。此规则统一应用于订阅详情、编辑和历史等所有底部弹层，均不提供下滑关闭。

底部从左到右固定一行三个等宽、等高的胶囊按钮。「删除」与「编辑／聊天」共用主题默认形状和内边距，均保留至少 48 dp 触控高度，文字基线对齐；颜色继续表达各自操作。

- **删除**：浅红色背景、深红文字，确认后从持续列表移除；保留已有聊天、图片和消费数据，可从已结束列表找回。操作只修改本地记录。
- **编辑**：浅蓝色背景、深蓝文字，修改现有订阅的信息及续费状态。
- **聊天**：白色背景、深色文字，先关闭详情再恢复该订阅唯一会话。

不提供“扣费流水与计划”“登记已关闭续费”“登记恢复续费”“登记已续期”“归档”“变更记录”入口。删除归档操作及变更记录的用户界面和加载逻辑；历史快照仍供金额统计、旧数据读取、操作去重及提醒周期识别内部使用。原流水数据层和未提交草稿继续兼容保存，不再挂载账单弹层。

取消下个月或下一年的续费可通过聊天说明，或在编辑中关闭自动续费、核对剩余有效期后保存。聊天提议确认后才写入；新取消状态为既有 `CANCEL_AT_PERIOD_END`，原下一扣费锚点和历史保留。普通非自动续费项目不会被误标为已取消。恢复自动续费后重新显示预计扣费日期。明确的新一期续期仍可从聊天确认，不自动生成实际付款流水。

仅自动续费且持续中的订阅按周期在首页提前三天展示扣费提醒。取消自动续费后取消未处理的提醒。原有提醒偏好及交付回执保留，首页的完成操作仅记录处理结果，不生成付款事实。

## 全屏图片预览

详情图片、聊天中的截图和待发送缩略图共用全屏预览。图片按原比例完整显示在黑色画布上，保留系统安全区域，不加“订阅图片”标题栏、圆角面板或固定比例外框。仅右上角悬浮关闭按钮，系统返回也可关闭；退出回到原详情或聊天，保留滚动与草稿。

只在打开时从本地持久文件按需解码，后台读取并限制解码边长，缩略图不加载整张大图。加载中显示进度，原件不可读时显示实际错误提示，不改写原图或上传媒体。

## 紧凑编辑表单

编辑页使用一张连续的左右两列表单，左列104 dp统一展示字段名，右列显示可编辑值、日期或选择控件。普通行最小48 dp，细横线分隔，不再使用独立的悬浮标签输入框或大小不同的外框。标签13 sp、内容14 sp，字体放大时允许行高自然增加；备注可多行、图片行按缩略图尺寸增加高度。

名称、费用、币种各占一行；间隔按天数／周数／月份／年数动态命名，同一行右侧填写数值并选择单位。自动续费和月底扣费以“是／否”配合勾选显示，整块右侧单元格可点。日期保持直接输入和日历选择两种方式；支付方式、账号、备注和图片也在表格中对齐，备注跟在账号后。保留原字段校验、草稿恢复、保存及稍后继续，表格正文可随键盘滚动，底部操作固定。

## 共用日程输入交互

底部以当前实际日程输入栏为准，不采用概念图里独立摆放的两个图片按钮。日程与订阅共用 `ui/common/BotComposerWorkspace.kt`，保留以下行为：

- 左侧加号旋转并展开媒体面板，提供拍照、相册、文件和最近图片；再次点击或系统返回可收起。
- 相册和文件使用日程已有的系统选择器，最近图片使用相同的授权、分页与选中顺序标记。
- 输入栏最多显示三行，支持键盘发送；选择媒体时收起键盘，聚焦输入时关闭媒体面板。
- 待发送截图显示缩略图、移除和继续添加入口，点击可预览；当前订阅解析支持图片，其他文件不会冒充已识别的截图。
- 发送时收起媒体面板与键盘，并在输入栏上方打开带遮罩的会话浮窗；关闭、返回、清空操作和动画采用共用实现。
- 关闭已有订阅会话后，底栏回到新订阅会话；不同订阅的输入与附件隔离，系统选择器及拍照结果绑定发起时的会话。

日程的数据读取、草稿、发送、AI 执行与附件保存仍由原有 ViewModel 和 Repository 负责，订阅复用其工作区交互而不修改日程业务。

## 聊天创建与本地保存

消息、未发送输入、待确认操作及图片关联保存到主库 schema 15，原图复制到本地持久目录。关闭、重开、退出或进程重建均可继续原会话。每次最多发送5000字与4张图片，旧消息按需读取。已发送图片从待发栏移到对应消息中，移除待发图片不会删掉已发送原图。发送失败保留输入；模型解析失败时保留已发送消息和截图，提供重新解析。

截图先可靠导入本机。仅在用户发送或重试解析时，向已配置模型发送本会话所需的有限文字和最多4张压缩图片，不发送其他订阅、未发送输入或全部个人历史，不使用远程文件存储。拍照暂存在现有持久导入暂存区，导入后删除拍摄暂存副本。模型断网、配置或鉴权失败不能影响已有卡片、详情、流水与本地统计。

待确认提议和操作 ID 持久保存；重复确认只能产生同一张卡片。保存成功回复与正式业务在同一事务提交，失败不显示“已创建”。解析中断后由用户明确重试，不在启动时自动重发模型请求。旧界面预览文案不再作为当前流程。

## 手机验收

1. 打开现有订阅详情：仅显示基本信息和备注；账号下一项就是备注；不再出现账单、归档、变更记录、续费快捷按钮或提醒设置与计划说明。
2. 底部同一行显示白色“聊天”、浅蓝“编辑”、浅红“删除”；点击聊天打开原会话；返回列表后位置保留。放大字体、切换深浅主题，按钮文字不重叠且正文可滚动。
3. 分别选择月付和年付订阅，在编辑中关闭自动续费并核对有效期；保存后列表与详情的下次扣费均显示“已取消续费”，到期前仍在持续列表，重启后状态不丢失。重新开启自动续费后恢复日期显示。
4. 通过原订阅聊天说明已取消下个月／下一年续费，核对提议并确认；同一条提议重复确认不重复保存，其他订阅不改变。
5. 点击删除后取消确认，记录应保持原样；确认删除后移出持续列表，原聊天和截图仍可从已结束列表打开，既有上月实际消费不变。
6. 到期记录显示“已到期”，不产生归档动作；在编辑或聊天中明确登记新的有效期后可继续使用并获得新一期提醒，同一期日期更正不重复提醒。
7. 默认提前三天的系统提醒仍可在后台出现，点击打开对应详情；旧日程提醒和其他Bot功能保持原有行为。系统调度与实际体验由用户在手机验收。

8. 点击编辑后，名称、费用、币种、间隔和自动续费应左列对齐、右列填写，普通行高度紧凑一致。修改金额、切换周期／续费并选择日期后保存，核对详情；输入不完整时稍后继续，再次进入应保留原始草稿。放大字体和弹出键盘后，备注、日期和底部保存仍可操作。

9. 从详情图片、聊天消息和待发截图分别进入预览，应是整屏黑底图片，无额外标题和圆角框。竖图、横图按比例完整展示；点击右上角关闭和系统返回，均回到原位置，聊天草稿和待发图片不丢失。

10. 在详情标题、图片及正文上分别上下拖动，面板整体应保持固定，正文到顶后下拉也不会关闭。长正文仍能内部滚动，标题及底部按钮保持固定；分别测试系统返回、X和面板外遮罩关闭，再重开详情并进入图片、聊天及编辑，过渡和内容恢复正常。

11. 长名称订阅在持续及已结束列表中均只占一行，末尾以省略号截断；短名称仍完整显示。放大系统字体后，标题不换行，扣费日期与金额仍在下一行；点击卡片进入详情可查看完整名称。

12. 对比调整前的订阅卡片：上下留白和两行间距进一步缩小，普通字号下高度约52 dp，图片随内容高度贴近上下边缘；标题、扣费日期及金额仍可读。检查无图和有图、持续和已结束列表，并在大字体下确认图片填满内容高度、文字不裁切、整张卡片仍可点击进入详情。横图和竖图的原始尺寸不能撑高卡片。
