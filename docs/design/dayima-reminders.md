# 大姨妈本地提醒

以真实开始记录计算周期预测，准备提醒默认在预测范围开始前一天，缺失记录提醒在范围结束后的第一天。缺少连续有效历史时不生成预测计划。两类提醒都在首页按日期显示，周期和种类共同确定稳定标识。

大姨妈顶部「提醒」可分别开启两类提醒，查看保存的提前天数。提前量也可用聊天规则修改。本地任务在启动、回前台、跨日和定期维护时按实际数据重新核对。规则关闭或来源删除时取消尚未处理的卡片。

实际开始日期写入与已出现的补记提醒完成记录在同一事务。补记后，已完成的记录保留在原提醒日期。撤销或更正实际记录时重新核对待处理状态。历史迁移 19→20 增加的 `dayima_reminder_plans` 和 `home_events` 继续保存这些数据及旧版投递结果。

手机验收时，有可用预测的用户可检查准备和补记日期，再补记正确的开始日期，核对首页的完成历史。关闭开关后，对应的未处理提醒应从首页取消。
