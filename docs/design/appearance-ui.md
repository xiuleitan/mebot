# 外观主题

## 两个基础主题

入口为设置首页的“外观与主题”。页面保留返回按钮和页面标题，正文仅显示一行等宽主题卡片：左侧“基础亮色”，右侧“基础暗色”。亮色色卡为四段，暗色色卡为五段，下方显示名称；移除介绍、自动保存说明和亮暗分组标题。

两款主题共用 灰阶参考图。基础亮色沿用原配色；基础暗色保留两档中间灰阶，移除最暗的 `#242424`，让背景、卡片与选中容器整体更明亮。

| 主题 | 明暗 | 背景、容器、灰阶及文字色值 |
| --- | --- | --- |
| 基础亮色 | 亮色 | `#F2F2F2` / `#FFFFFF` / `#CCCCCC` / `#1A1A1A` |
| 基础暗色 | 暗色 | `#2C2C2C` / `#3B3B3B` / `#4A4A4A` / `#595959` / `#F2F2F2` |

基础暗色背景使用 `#2C2C2C`，卡片基础面使用 `#3B3B3B`，选中容器和 `surfaceContainerHigh` 使用 `#4A4A4A`，`surfaceContainerHighest`、亮表面和中灰共用 `#595959`。文字使用 `#F2F2F2`，次级文字微调为 `#D0D0D0`，保证在最亮的暗色表面上仍有足够对比。实际颜色角色独立定义，色卡按角色生成并去重，共用同一灰阶的角色仅显示一段。

## 交互与布局

- 点击任一选项立即应用，以加粗边框和底色表示当前主题，并保留无障碍单选语义。无需确认或保存按钮，设置首页继续显示当前主题名称。
- 两个主题覆盖首页、侧栏、设置、日程、日期栏、完成按钮、详情与新增日程浮层，以及状态栏和导航栏图标明暗。设置图标沿用灰阶，日程提醒图标保留语义色。
- 基础暗色侧栏卡片保留此前提亮效果，区分于侧栏背景；选中态更亮，切换使用 200 毫秒颜色过渡。
- 应用颜色使用 240 毫秒过渡，选中边框使用 200 毫秒过渡，连续切换从当前颜色继续，遵循系统动画设置。不重建 Activity，不重置日期、完成状态或列表位置。
- 页面最大宽度 720 dp。两个选项始终放在同一行、等宽排列，间隔 12 dp，不因字体缩放改为上下布局。每张卡片内边距 10 dp，预览高度 80 dp，下方名称与预览间隔 10 dp；名称随系统字体缩放。亮色色卡沿用 41% / 26% / 18% / 15% 的分段比例；暗色色卡使用 34% / 22% / 17% / 15% / 12%，让五档颜色均可辨认。
- 顶部返回和系统返回先回设置首页，再返回此前页面。侧栏展开时系统返回先关闭侧栏，页面过渡保持原有行为。
- 仅在主题保存失败时保留错误提示，并允许点击当前主题重试。

## 本地偏好与旧版兼容

- 当前保存的稳定 ID 为 `basic_light`、`basic_dark`，不使用枚举序号。
- 旧版亮色 ID `mist_rose`、`clear_blue`、`frost_blue`、`warm_sand` 读取为基础亮色；旧版暗色 ID `deep_ocean`、`pine_green`、`starry_purple`、`stone_teal` 读取为基础暗色。升级时保留用户原来明确选择的明暗偏好，页面始终有对应选中项。
- 首次未选择时，系统亮色默认基础亮色，系统暗色默认基础暗色。明确点选后由本地选择控制，不再随系统切换。
- `AppearanceViewModel` 管理当前主题与保存错误，`ThemePreferences` 在 IO 线程读写 SharedPreferences；首次绘制前加载偏好，连续切换串行提交并保留最新待写值。
- 本次不修改业务数据库、日程、铃声或模型配置，不增加网络请求或权限。

## 手机验收

1. 进入设置 → 外观与主题，确认标题下只有一行，左侧基础亮色仍为四段，右侧基础暗色为五段；原最暗一档已移除，背景和卡片更亮且仍能区分，两档中间灰阶衔接自然，下方显示名称，没有介绍或分组说明。
2. 分别点击基础亮色和基础暗色，确认加粗边框与选中底色始终只有一项；返回设置、侧栏和日程检查背景、卡片、文字和系统栏同步切换，暗色侧栏卡片仍可辨认。
3. 连续切换后重启应用，应保留最后选择。已手动选择后更改系统明暗，应用选择保持不变。旧彩色选择升级后按原明暗恢复为对应基础主题。
4. 在日程页选定其他日期并滚动，进入设置切换主题后逐级返回，日期、完成状态和浏览位置保持；侧栏开关及返回过渡连贯。
5. 放大系统字体、横屏和小窗口，检查两张卡片始终左右并排，两幅色卡、名称与返回按钮可见可点，不重新变成上下两张卡片。

编译与安装由助手完成，手机上的功能、交互与体验验收由用户完成。

## 应用图标

在「设置 → 外观与主题」的「应用图标」中，点选「粉色 M」或「经典头像」。首次使用默认选中粉色 M。桌面入口和当前选项由 Android 保存，换图标时两种入口都指向同一个首页 Activity。安卓 13 及以上一次提交两项入口状态，旧版先启用新入口再停用旧入口。图标预览使用各选项的自适应图标资源。

手机上分别切换两次，每次返回桌面查看图标并从桌面重新打开应用。设置页的选中项应与桌面图标一致。
