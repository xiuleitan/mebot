## 页面与操作

| 区域 | 当前实现 |
| --- | --- |
| 侧边栏 | 沿用既有档案入口和全局侧滑，不改其他 Bot 导航 |
| 顶部 | 左侧菜单、右侧回主页按钮为 48 dp，中间语义搜索框为 44 dp，垂直居中、比两侧稍矮；搜索文字与图标垂直居中，去除撑高输入框的额外上下内边距。启用索引后直接在原区域按关联度排列；另有明确标注的离线文字查找，详情见[语义检索](archive-search.md) |
| 主内容 | 真实 Room 档案，按最近更新分页，每次 50 条；双列、等高卡片，标题按实际一至两行占位，图片填满剩余空间；有图显示封面，点击卡片任意区域（包括封面）统一打开档案详情；没有图显示正文或字段开头，不显示日期 |
| 空列表 | 显示本地建档提示，不写入或展示示例个人资料；读取失败与空列表区分 |
| 详情 | 点击卡片展示正文、字段、标签、原始链接及本地附件；正文/字段/链接可复制，HTTP(S) 链接主动点击后打开；“编辑档案”直接进入该卡片首次建档的完整聊天记录，可继续补充；左侧「删除档案」先显示日程样式确认框，取消保留详情，确认后才执行删除；见[统一约定](detail-deletion.md) |
| 底部登记 | 首页始终登记新档案，首次发送建立它自己的聊天；关闭聊天或保存后回到新建输入。直接使用日程共用的 BotComposerWorkspace；加号、相册/文件/相机、发送、媒体面板与聊天浮窗沿用既有交互和动画 |
| 独立会话 | 一次会话只绑定一份档案；从底部输入开始 AI 建档，从已保存卡片的详情回原会话，支持消息分页、各自输入与附件恢复；首页不再放新建和会话记录按钮，历史数据保留 |
| 手动编辑 | AI 产生草稿后可核对、手动修改；已有档案详情进入原会话后仍可手动编辑。填写标题、正文、类型、逐行标签、任意字段和链接，可选本会话附件及封面；不在空白会话提供“手动建档”按钮 |
| 搜索配置 | 统一放在 App 设置 → 模型与 API → 档案语义搜索，首页没有“索引”按钮；启用保存一次，以后确认档案自动更新索引 |
| 保存与删除 | 确认成功才显示保存结果，连点不重复创建；从既有档案继续编辑保持 ID；冲突不覆盖新内容，重新载入需明确确认。删除只移除正式卡片，相关聊天历史与附件仍保留 |

所有卡片总高度按两行标题和基础预览区统一计算；按 2026-10-28 的红框参考，将基础预览高度从 144 dp 降为 72 dp，普通字体下总高约 148 dp，约为原来的三分之二。标题自身不强制预留第二行，一行标题时图片多获得一行高度，两行标题时图片相应缩小，超长标题最多两行并省略。图片按权重填满剩余空间，继续按比例裁剪，不拉伸原图；图片卡片的搜索摘要最多一行，给紧凑封面保留显示空间；放大字体时统一卡片高度随两行标题的字体高度同步调整。无图卡片继续显示可容纳的正文开头。列表预留输入框和媒体区域空间。详情、编辑、历史使用可中断的底部弹层动画，发送沿用日程聊天浮窗过渡；保存完成后先收起编辑面板，再打开详情。

2026-10-28 收紧卡片详情：内容区顶部留白改为 8 dp、底部 12 dp，条目间距从 16 dp 缩为 8 dp，正文行距改为 22 sp。具体信息按左右两列显示，左侧约 32% 为字段名称及冒号，右侧约 68% 为内容；统一行高但不固定条目高度，地址、证件号码和长字段名均完整自然换行，右侧内容继续支持选择复制。附件标题间距缩为 6 dp，底部删除/编辑固定并排，保留至少 48 dp 触控高度，不随正文滚动离屏。仅修改档案详情布局，不改首页卡片、原会话、数据或其他弹层的布局。

档案详情关闭面板本身的拖动手势及拖动条：上下滑动仅滚动内部内容，滚到顶部或底部后继续滑动也不带动面板或下拉关闭。保留系统返回、右上角 ×、点击详情外遮罩关闭，继续使用原有开合动画；编辑、历史和搜索设置等其他档案底部弹层也统一禁用拖动关闭。手机验收需分别覆盖内容中间/顶部/底部连续滑动不关闭、三种明确关闭方式、返回首页后重新打开详情，以及编辑和附件查看。

按用户 2026-10-27 的手机反馈修正会话入口：首页输入不再沿用上一张卡片或未确认会话；退出聊天时先保存输入，退场动画完成后切换到新建入口。首页尚未发送的文字和附件在查看/编辑其他卡片期间独立保留，回到首页时恢复；已保存档案中的未发送补充和附件，通过对应卡片继续。卡片通过 `sourceSessionId` 精确定位原会话，不用最近 100 条历史猜测，不因重复编辑而创建另一条聊天记录。2026-10-28 按用户要求移除全局会话记录入口，底层历史不拆分或删除。本轮仅调整 UI 与状态职责，沿用已回流的主库 schema 19，不修改持久化格式。

## 本地保存与恢复

- 标题、字段、链接、正文、输入、聊天记录和附件元数据仍在共用主库的密文中，原件仍在档案自有持久目录。未配置模型或断网时可完成本步全部管理功能。
- 输入立即显示并串行持久化，保存过程中显示状态；切换会话、关闭表单或离开页面前刷新未提交输入，写入失败则保留原草稿和重试入口。已成功持久化的草稿、消息和附件在重启后恢复。
- 选择器启动时固定接收会话，返回结果即使发生在切换或 Activity 重建后，仍交给原会话；导入操作排队处理，不因其他本地操作忙碌而丢结果。
- 手动编辑未确认时，继续发送补充消息不会擦掉已有手动字段。只有正式确认才更新卡片，原始聊天与链接一直保留。
- 新建/切换入口不删除旧会话；从详情进入关联会话，也不会把另一个会话的输入带入目标。

## 附件查看与缓存

图片在 IO 线程按需认证解密、处理方向并缩放预览；认证结束后才交给 UI，原件不改写。通用文件可主动选择“使用其他应用打开”。仅此操作生成 `cacheDir/archive_exports` 内不含业务名称的独立查看副本，通过现有 FileProvider 的单份 content URI 授予临时读取权限。

2026-10-29 图片改为黑底全屏相册：主页卡片包含封面在内的全部区域统一打开详情；详情中的附件图片移到正文之后、字段列表之前（如“姓名”上方）。点击详情缩略图或会话图片进入全屏相册，点击哪张便从哪张开始，按当前档案/会话附件顺序左右翻页，去重并排除普通文件，不混入其他档案。完整图片按比例适配屏幕，不使用文件名标题栏、灰色圆角图片框或固定宽高比；左上角显示多图页码，右上角 × 或系统返回关闭，回到原来的详情位置。仅当前页及相邻页按需解码，最长边限制为 2048 像素，取消或离开页面不保留整组大图。

全屏右下角“下载到本地”保存**当前页的原始图片字节**，不重新压缩、不改变方向数据或档案内原件。Android 10 及以上通过 MediaStore 保存到 `Pictures/mebot`，可在系统相册找到；先认证原件，再创建 `IS_PENDING` 目标，流式复制并关闭输出成功后才发布，认证失败不创建公开目标，写入失败或取消清理本次目标及临时明文。进程中断留下的未发布媒体由系统 pending 生命周期管理。Android 8/9 使用系统创建文件选择器保存，不新增共享存储写入权限。成功下载的副本独立于查看缓存，缓存回收或删除档案不会清理它。保存操作绑定点击时的图片 ID，翻到另一页不会保存错图；翻页动画期间不接受下载点击，写入中防止重复提交。

查看副本上限为 10 份、总量 200 MiB；创建新副本前回收过期或最旧副本，原件不参与该清理。一小时后 WorkManager 任务可执行清理，同时下次进入档案和创建副本前也进行恢复清理；清理时回收对应读取授权。系统可能延后后台任务，应用停止时不承诺精确时刻的物理删除，也不能收回查看器已自行复制的内容。取消、认证失败及导出中断会清理私有暂存文件。

公共范围已由集成会话确认，记录为 Git 公共目录中的 `mebot-integration/scopes/archive-step2.json`；共享资源只追加 `attachment_paths.xml` 的 archive_exports 专属缓存路径，不开放缓存根目录、加密原件或外部存储根目录。主库结构、历史迁移和不可换绑触发器保持不变。

## 手机验收

1. 进入档案，确认顶部搜索下不再显示“新建档案、索引、会话记录”。直接从底部发送文字和图片，AI 生成草稿后点“核对整理草稿”修改并保存，列表出现真实卡片；分别点击标题、空白和封面都应先打开详情，附件缩略图位于“姓名”等字段之前，不在首页直接弹出大图。
2. 添加两张图片和一个普通文件，发送后核对 AI 草稿，选择附件/封面并保存。详情点第二张图片应从第 2 张全屏打开，左右滑动只切换这份档案的图片，普通文件不进入图片相册。右下角分别下载前后两张，在系统相册的 mebot 相簿确认图片不同、完整且方向正确；返回后档案、图片及聊天仍在。普通文件仍能通过系统其他应用打开。
3. 分别建立银行卡、身份证两份档案，各自在详情进入原会话，留下不同的未发送输入和附件，来回切换后关闭并重启 App，从各自卡片继续，确认内容不混用。
4. 点击银行卡卡片看详情，再点“编辑档案”，预期直接打开银行卡原聊天；继续补充或手动核对保存只更新原卡片。关闭聊天回到首页，直接输入身份证资料应开启另一会话。填写重复链接和含查询参数的 URL，保存重开后核对原地址、顺序和数量。
5. 断网时手动编辑已有档案、查看详情和附件，列表仍可用。AI 建档失败保留消息和附件，恢复网络可重试。顶部新语义查询明确显示联网/配置状态，可主动选择“本地文字查找”，不把它伪装为语义结果。
6. 明确确认删除一条测试档案，核对卡片移除，另一条档案及其原聊天、原有日程/订阅/闪念/健康记录不受影响；检查深浅色、大字体、返回和连续开合弹层。
7. 从 App 设置 → 模型与 API 配置档案语义搜索，确认旧配置保留、取消不保存、启用后自动处理已有及以后新增档案；更改搜索配置不影响语言/图片模型或首页未发送的文字和附件。
