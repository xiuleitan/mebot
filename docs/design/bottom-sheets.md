# Bot 底部弹层

2026-10-29：所有 Bot 底部详情、编辑、历史、说明面板及任务浮窗统一使用 56% 黑色背景遮罩，使弹层成为视觉焦点。遮罩颜色由 `ui/common/BotSheetScrim.kt` 定义；沿用原有入场、退出、系统动画设置和遮罩点击关闭行为。

| 入口 | 遮罩与动画 |
| --- | --- |
| 日程详情 | 共用遮罩随现有入场进度变化；原生 SheetState 控制收起 |
| 闪念详情与编辑 | 共用遮罩随贴底 Dialog 的入退场进度变化，继续保持右上角、遮罩和系统返回退出 |
| 订阅详情、编辑与历史 | 共用遮罩随原弹层入场进度变化 |
| 档案详情、编辑、历史及设置 | 所有 ArchiveSheet 统一使用共用遮罩 |
| 大姨妈详情、编辑、标记、图表、历史与阶段说明 | 各 ModalBottomSheet 显式使用共用遮罩 |
| 各 Bot 任务浮窗 | 共用工作区使用同一遮罩，继续随浮窗可见性淡入淡出 |

## 明确关闭，正文独立滚动

2026-10-29：所有 Bot 底部页面禁用弹层自身的拖动手势，手指下滑、快速下甩、正文滚到顶后继续下拉都不能移动或关闭整个页面；正文仍可正常上下滚动。移除拖动横条，保留系统返回、点击弹层外遮罩、右上角叉号；日程加载／失败状态和大姨妈历史页也提供明确关闭入口。保存、完成、恢复等已授权的程序收起继续使用原有动画，写入过程中的保护及草稿落盘检查保留。

订阅与档案的共用弹层不再提供可开启拖拽的配置，编辑、历史、设置和详情均遵守同一规则。闪念贴底 Dialog 与任务浮窗原本没有拖动关闭逻辑，继续沿用。大姨妈阶段详情继续保留当前手机已安装的四张本地科普示意图。

## 完成与恢复后收起

日程和闪念详情中的完成／恢复操作，仅在当前记录达到请求的状态、写入结束且没有失败提示时自动收起，保留各自原有退出动画。正在写入时继续显示详情并禁用重复操作；失败时保留正文与提示，允许重试，重试成功后收起。

只有从本次详情主动发起的完成／恢复请求会触发自动收起。打开一条本来已完成的记录、后台刷新状态或切换到另一条记录，不会自动关闭新详情。列表及聊天内的完成切换沿用原有行为。

本轮只调整弹层呈现和完成后的退出，不修改 Room 结构、持久文件、实际完成／恢复的写入逻辑与业务数据。

## 手机验收

1. 依次打开五个 Bot 的详情、编辑、历史、说明及任务浮窗，在标题与正文上向下拖动或快速下甩，页面应保持固定；正文到顶后继续下拉也不退出。正文仍能向上滚动，背景遮罩保持一致。
2. 在闪念、日程分别打开未完成记录并点击完成，保存结束后弹层自动收起，列表正确更新；重新打开已完成记录，执行恢复后也自动收起。
3. 打开已完成记录但不操作，弹层应保持；连续切换两条详情，不能因上一条状态更新而关闭当前记录。
4. 分别使用右上角叉号、弹层外遮罩及系统返回退出，确认三种方式都可用且过渡连贯；编辑时先收起键盘再返回，未发送草稿仍保留。长正文、图片预览、编辑、删除确认和完成后自动收起仍可用，亮暗主题及关闭系统动画时无残留遮罩。
