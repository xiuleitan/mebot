# 设置页面

## 范围与参考

按用户提供的 设置页面参考 绘制 UI，在 侧栏位置参考 的 mebot 标题右侧增加设置齿轮。参考图只提供页面内容和视觉参考，Android 系统状态栏、导航栏由系统绘制。

“外观与主题”提供 [主题选择和应用图标设置](appearance-ui.md)，摘要显示当前主题。“通知提醒”提供 [系统日历授权、登记状态和提醒测试](schedule-reminders.md)，以及交易通知权限入口。经期和订阅扣费提醒在首页查看。“模型与 API”的配置保存在本机，连接检查在用户点击时发起。

## 布局与视觉

- 设置入口与侧栏标题水平对齐，按钮触控区域 48 dp，使用 25 dp 描边齿轮，保持原有侧栏宽度和日程卡片布局。
- 设置页保留 Android 返回箭头，下方为 34 sp 的“设置”大标题。内容最大宽度 720 dp，两侧留白 24 dp。
- 背景、圆角卡片、文字与箭头跟随应用主题，保留柔和阴影。每张导航卡片左侧使用本地矢量图标，中间展示名称及适用的说明，右侧为箭头。基础亮色与基础暗色均使用灰阶图标及底色。
- 触觉反馈开关下方依次是通知提醒、外观与主题、模型与 API 和交易系统。
- 卡片由内容决定高度，文字允许换行；标题与卡片一起纵向滚动，顶部返回按钮固定可见。内容避开系统安全区域，明暗以应用中选择的主题为准。

## 导航与状态

- 首页或日程页打开侧栏后点击设置，侧栏沿现有 320 毫秒动画收起，设置页以短距离位移和淡入显示。
- 顶部返回按钮和系统返回均回到进入设置前的首页或日程页，使用对应方向的退出过渡。日程选择的日期、完成状态和网格浏览位置保留；设置页自己的列表位置也作为界面状态恢复。
- 已在设置页时再次点击侧栏齿轮仅关闭侧栏，避免把设置页记成自身的返回目标。设置页内从侧栏选择日程，沿用原有规则定位到设备当天。
- 设置页左侧 16 dp 保留拉出侧栏手势。侧栏展开后，遮罩点击、左滑、系统返回及返回手势取消继续使用原有处理。系统返回优先关闭侧栏，再返回前一页面。
- 四张导航卡片分别打开对应页面，返回后恢复设置列表的滚动位置。从这些页面点击侧栏齿轮回到设置首页时，保留进入设置前的返回目标。
- 页面切换沿用 Compose 动画时长机制，遵循系统动画设置。

## 手机验收

1. 首页打开侧栏，确认 mebot 右侧出现齿轮，日程卡片位置保持一致；点击齿轮应收起侧栏并进入设置页，切换没有闪白或残留遮罩。
2. 确认页面显示触觉反馈开关和四张导航卡片。依次打开通知提醒、外观与主题、模型与 API 和交易系统，确认进入对应页面。外观卡片仍显示当前主题，两款基础主题的图标均呈灰阶。
3. 从首页进入设置，分别用顶部返回箭头和系统返回退出，均回到首页。
4. 从日程页选择一个非今天日期，改变示例完成状态并滚动，再打开侧栏进入设置。分别使用顶部箭头和系统返回，确认回到同一日期、同一浏览位置，完成状态保持；日程详情、日期横滑和新增浮层仍可操作。
5. 设置页从左边缘拉出侧栏，检查遮罩点击、左滑、系统返回、返回手势取消，以及展开中断后再次打开。关闭侧栏应留在设置页；再次点击齿轮后返回仍应回到原页面。从侧栏点击日程则应定位今天。
6. 连续进入和退出设置，滚动后切后台再回来，并旋转屏幕，检查页面与滚动位置恢复、按钮响应和遮罩清理。
7. 切换应用主题并放大系统字体，检查卡片名称与说明完整换行、图标清楚、返回按钮易点。横屏与小窗口允许滚动到底，所有内容避开状态栏和系统导航区。

手机上的功能、体验与回归测试由用户完成，构建和安装结果在交付中报告。

## 模型与 API（0.5.0）

- 通过设置卡片进入，沿用主题背景、圆角卡片、返回箭头和页面位移／透明度过渡。键盘出现时页面缩进并可滚动，大字体与横屏下输入框允许换行。
- 默认语言模型 `qwen3.8-flash`，图片模型 `z-image-turbo`，图片尺寸固定 768×768。接口地址保存为完整 HTTPS URL，默认使用北京地域旧域名；两个模型共用百炼 API Key。可改成其他地域或业务空间专属域名，需与 Key 地域匹配。语言地址若以 `/v1` 结尾，保存时补全 `/chat/completions`。
- 编辑后点击“保存配置”。模型名及地址先在本地校验，拒绝空模型名、HTTP、URL 中的账号／查询串／片段和占位符；Key 不包含 Bearer 前缀或内部空白。Key 输入留空保留旧 Key，“移除已保存的 Key”独立移除凭据，其他已存配置不变，也不要求当前未保存字段有效。
- `model_settings` 是主库中的单行配置表，保存模型名、接口、尺寸、版本及加密后的 Key 和随机 IV。Android Keystore 持有不可导出的 AES-256 密钥；AES-GCM 每次加密使用新 IV 与认证标签。主库 schema 2 → 3 只增加此表，不清理既有任务或草稿。
- 页面只读取已保存 Key 的存在状态，不回显明文；新的 Key 输入使用密码框，只在 ViewModel 内存保留，禁用该输入区域的 SaveableStateRegistry。成功保存或移除后清空输入，不写 Bundle、日志或普通偏好；备份与设备迁移排除本地数据。Keystore 无法解密时保留密文并提示重新输入，不自动清空或误报 Key 无效。
- 仅在已保存且没有待保存修改时允许检查。语言请求为固定短句，关闭思考及流式输出，限制 16 个输出 token；图片请求固定 768×768、关闭提示词扩写。两种检查分别点击，按钮附近明确说明调用可能计费；不发送日程、聊天历史或附件，不下载、保存测试图。配置成功不等同于已经实现 AI 日程增改删。
- 两个接口分别展示结果。401／Key 错误、403／模型授权、未开通服务、额度不足、模型不可用、地址与参数错误、429 限流、服务异常、DNS／网络、超时及证书问题有不同提示。HTTP 成功但无有效文本／图片结果仍报响应格式异常。服务端原始 body、message 和图片临时 URL 均不展示或记录，避免回显凭据；结果只含分类、HTTP 状态及耗时。
- 网络在 IO 线程执行，使用系统 TLS 验证，禁止跟随重定向、自动重试及明文流量，限制响应体为 128 KiB。单次文本／图片读取超时分别 30／60 秒，额外限制总等待时间。检查中暂时禁用配置修改，支持“停止等待”；离开页面取消本机等待。取消不承诺服务端撤回，提示请求仍可能在处理，迟到结果不覆盖新状态。检查结果仅为当前操作的即时结果，不持久化成永久可用状态。

默认接口与请求格式依据 [阿里云文本接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope) 和 [Z-Image 接口](https://help.aliyun.com/zh/model-studio/z-image-api-reference) 核对；凭据保护使用 [Android Keystore](https://developer.android.com/privacy-and-security/keystore)。

### 开发机验证

使用假 Key、AES-GCM 测试密钥和模拟 HTTPS 连接验证加密随机性、篡改拒绝、关闭重开、替换／保留／移除 Key、验证与事务失败回滚、并发版本拒绝、schema 2 → 3 保留旧草稿，以及各类 HTTP／网络错误、响应校验、大小限制、重定向拒绝及取消断开连接。ViewModel 覆盖默认工厂创建、明文输入清理、不带明文的页面恢复、未保存内容阻止联网、移除与取消后的状态。测试不调用真实收费接口，未使用真实账号凭据；真实端到端连通由用户在手机填写 Key 后检查。

## 模型与 API 专项验收

1. 从侧栏齿轮进入设置，打开“模型与 API”，检查两个默认模型与地址、768×768、Key 未配置状态；返回键逐级返回设置及原先日程页，日程日期、完成状态和草稿保留。
2. 在手机填写自己的百炼 Key，点击“保存配置”。成功后密码输入清空，显示 Key 已安全保存；关闭／重启后返回本页，模型与地址保留，Key 仍显示已保存且不回显明文。替换 Key 后再次保存，应继续如此。
3. 分别点击语言和图片的“检查连接”，应显示进度，其他配置暂时不可编辑；成功显示模型返回有效结果。图片检查会生成一张测试图并可能计费，请按需执行，不会生成日程卡片或保存测试图。
4. 使用一个无效测试 Key 保存后检查，应提示 Key 错误，不能误报网络故障；开启飞行模式再检查，应提示网络／域名问题，不能误报 Key 无效。恢复网络、正确 Key 后重新保存检查。其他权限、额度与限流情况按实际账号返回判定。
5. 输入 HTTP 或无效地址并保存，应在本地提示配置错误，修改保留；尚未保存时检查按钮不可用。修改某个模型名或地址后，旧的检查结果应清除。
6. 点击“移除已保存的 Key”，应显示尚未保存 Key，重启后保持；模型与地址仍在，检查按钮不可用。即使输入框正在填写一个无效地址，也应能移除已有 Key，未保存的地址文字仍保留。
7. 检查过程中点击“停止等待”或返回页面，再重新打开，不能被迟到响应改成成功。取消只停止本机等待，服务端可能继续处理，手动再次检查可能另产生费用。
8. 切换明暗主题、放大字体、旋转屏幕和弹出键盘，检查所有字段、保存、移除、检查及停止按钮可见可点，内容可滚动，未保存的 Key 不以明文显示。返回日程后检查最近草稿恢复／清空、完成排序及详情阴影仍正常。
